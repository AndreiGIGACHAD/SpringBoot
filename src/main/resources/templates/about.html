ABOUT ELECTRONOVA

О приложении

Название: ELECTRONOVA — учётный веб-каталог магазина электронной техники.

Назначение: хранение каталога товаров, категорий, цен и складских остатков.

Основные разделы: бытовая техника; цифровые товары; комплектующие ПК; компьютеры и периферия; аудио и видео; игры и развлечения.

Технологии: Java 21, Spring Boot, Spring MVC, Spring Security, Spring Data JPA, Thymeleaf, H2 Database и Actuator.

Безопасность: пароли хранятся в хешированном виде; новые пользователи получают роль READ_ONLY; USER управляет собственными записями; ADMIN имеет полный доступ.

Разработчик: укажите ФИО студента.

Назначение работы: учебный проект для демонстрации CRUD-операций, ролевого доступа, работы с БД и журналирования.
