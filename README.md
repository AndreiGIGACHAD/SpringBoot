# Магазин техники

## Запуск
1. Откройте проект в IntelliJ IDEA.
2. Выберите JDK 21.
3. Дождитесь загрузки зависимостей Maven.
4. Запустите `src/main/java/ru/example/electroshop/ElectroShopApplication.java`.
5. Откройте `http://localhost:8080`.

Демо-учётная запись администратора: `admin` / `admin12345`.

## Основные возможности
- Каталог товаров и управление категориями.
- Добавление, редактирование и удаление записей согласно роли пользователя.
- Роли `READ_ONLY`, `USER` и `ADMIN`.
- Регистрация пользователей с ролью `READ_ONLY` по умолчанию.
- Калькулятор скидки и наценки.
- Журнал действий в базе данных и файле `logs/electronova.log`.
- Spring Boot Actuator.

## Структура исходного кода
- `config` — настройки безопасности и начальные данные.
- `controller` — обработчики страниц и форм.
- `entity` — сущности базы данных.
- `repository` — доступ к данным.
- `service` — бизнес-логика и журналирование.
- `src/main/resources/templates` — HTML-шаблоны страниц.
- `src/main/resources/static/css/style.css` — оформление интерфейса.
